# دليل أسلوب شورتس الفونك البرازيلي (Phonk / Aura / Velocity Edits)

مرجع لإنتاج شورتس "مشاهد + موسيقى فقط" بمونتاج ثقيل متزامن مع الإيقاع، باستخدام Remotion.

## 1. الموسيقى: الفونك البرازيلي
- **الأصل:** مزيج من الفونك الأمريكي (Memphis) مع الـ Funk Carioca البرازيلي، وأشكال مثل *funk automotivo* و *montagem* و *mandelão*.
- **السرعة:** غالباً 120–135 BPM (المرجع الشائع ≈130). هناك نسخ *Slowed / Super Slowed* منتشرة جداً في الـ Aura edits.
- **العناصر المميزة:** باص 808 مشوّه وثقيل، **الكاوبل (cowbell)** كلحن رئيسي، مقاطع صوتية مقطّعة ومعدّلة الطبقة، و"drop" قوي بعد بناء قصير.
- **البنية الأهم للمونتاج:** intro هادئ (1–4 ثوانٍ) ← build ← **DROP** (هنا ينفجر المونتاج) ← تكرار بأنماط.

## 2. أنواع المحتوى الرائجة
| النوع | المحتوى | الإحساس |
|------|--------|---------|
| Aura / Sigma edit | شخصية (لاعب، بطل فيلم/أنمي) بنظرة واثقة وحركات مميزة | هيبة، برود، "aura" |
| Car / Drift edit | سيارات، drift، طرق ليلية | سرعة، أدرينالين |
| Football edit | مهارات، أهداف، احتفالات | قوة، استعراض |
| Gym / Motivation | تمارين وأجسام | قوة، انضباط |
| Anime / Movie edit | لقطات قتال وتحوّل | ملحمي |

## 3. القواعد الذهبية للمونتاج
1. **كل قطع على ضربة:** القطع يقع على الـ kick أو الـ snare. قبل الـ drop قطع كل 2–4 ضربات، بعده كل 1 ضربة أو نصف ضربة.
2. **الخطّاف في أول ثانية:** أقوى لقطة (أو لقطة بنظرة للكاميرا) في أول 0.5–1 ثانية. لا مقدمات.
3. **الـ drop = ذروة الفيديو:** فلاش أبيض + zoom punch + shake قوي + أسرع إيقاع للقطع.
4. **المدة:** 10–30 ثانية غالباً، وتنتهي بطريقة تسمح **بإعادة التشغيل (loop)** بسلاسة لرفع نسبة المشاهدة.
5. **صيغة الإطار:** 1080×1920، 30 أو 60 fps (60 أفضل للـ velocity والـ shake).

## 4. قاموس المؤثرات (وكيف ننفّذها في Remotion)
| المؤثر | الوصف | التنفيذ |
|-------|------|--------|
| **Velocity / Speed ramp** | تسريع قبل الضربة ثم تبطيء شديد عليها | تحويل الزمن: `startFrom` متغير أو `playbackRate` ديناميكي عبر منحنى (ease) يُحسب لكل إطار |
| **Zoom punch** | تكبير مفاجئ 1.0→1.15 على الضربة ثم رجوع | `spring()` أو `interpolate()` على `scale` يبدأ عند إطار الضربة |
| **Shake** | اهتزاز للكاميرا على الضربات القوية | `translate`/`rotate` بقيم `random(seed)` تتضاءل خلال 4–8 إطارات |
| **Flash** | وميض أبيض 2–3 إطارات | `AbsoluteFill` أبيض بـ opacity 1→0 |
| **Motion blur / Directional blur** | ضبابية حركة في الانتقالات | `@remotion/motion-blur` (`CameraMotionBlur`/`Trail`) أو `filter: blur()` |
| **RGB split / Chromatic aberration** | انفصال القنوات اللونية | 3 نسخ من الفيديو مع `mix-blend-mode: screen` وإزاحات صغيرة |
| **Freeze frame + glow** | تجميد لقطة النظرة مع توهج | `<Freeze>` + `filter: brightness/contrast` + vignette |
| **Color grading** | تباين عالٍ، ظلال داكنة، تشبع منخفض أو أزرق/برتقالي، أحياناً أبيض وأسود | CSS `filter` (contrast, saturate, hue-rotate) أو LUT عبر WebGL |
| **Whip / Zoom transition** | انتقال سريع بالتكبير والضبابية | `@remotion/transitions` أو مكوّن مخصص |
| **Strobe / B&W flicker** | تبديل سريع بين ملوّن وأبيض وأسود على الضربات | `filter: grayscale()` يتبدل كل ضربة |
| **Grain / VHS / Vignette** | ملمس سينمائي خشن | overlay بصورة/فيديو noise بـ `mix-blend-mode: overlay` |
| **Text pop (اختياري)** | كلمة واحدة كبيرة على الـ drop | خط عريض (Impact / Bebas)، يظهر بـ scale spring |

## 5. خط إنتاج مقترح بـ Remotion
1. **تحليل الإيقاع مسبقاً (offline):** استخراج توقيتات الـ beats/onsets بأداة مثل *Essentia.js* (RhythmExtractor) أو librosa، وحفظها في `beats.json` مع تمييز الـ drop. يُفضّل أيضاً تعديل يدوي للتوقيتات المهمة.
2. **قوة الضربة لحظياً:** `useWindowedAudioData()` + `visualizeAudio()` لقراءة طاقة الترددات المنخفضة (الباص) في كل إطار، واستخدامها لتحديد شدة الـ shake/zoom.
3. **قائمة المشاهد (EDL):** ملف JSON يربط كل لقطة بمقطع زمني (من ضربة إلى ضربة) + المؤثرات المطلوبة.
4. **مكوّنات قابلة لإعادة الاستخدام:** `<BeatCut>`, `<ZoomPunch>`, `<Shake>`, `<Flash>`, `<VelocityClip>`, `<ColorGrade>` تُغذّى من `beats.json`.
5. **قالب واحد = فيديوهات كثيرة:** تغيير الأغنية والمشاهد فقط عبر `inputProps` ثم `remotion render`.

## 6. تنبيهات مهمة
- **حقوق النشر:** الأغاني الرائجة والمشاهد من أفلام/مباريات معرّضة لـ Content ID (تحويل الأرباح أو الحظر). الأفضل: موسيقى مرخّصة/خالية الحقوق أو من مكتبة YouTube، ولقطات مصوّرة أو مرخّصة.
- **الجودة:** لقطات بدقة عالية ونظيفة؛ المؤثرات تضخّم العيوب.
- **لا تبالغ:** ليس كل ضربة تحتاج shake + flash + zoom معاً؛ وفّر المؤثرات الثقيلة للـ drop والضربات القوية حتى يبقى لها أثر.
